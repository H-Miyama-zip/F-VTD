# F-VTD

VTuber変換辞書 ver1_2（とぷんろぷ氏、2026-09-03）を基に、福井関連VTuberを追加した非公式の改変版です。原作者・自治体・各VTuberの公式配布物ではありません。

## 今回の変更

2026-09-21：原版20,014語に36語を追加し、合計20,050語。

- 未収録18名のフルネーム読みと、下の名前・短縮読み17語を追加。カリチワはフルネームと同じ読みを使用。
- 収録済みの「響絵想」に公式の読み「ひびきえめもりー」を追加。原版の「ひびきめもりー」は互換用に保持。
- 「西山ちゃちゃ丸」の「にしやまちゃちゃまる」は暫定読み。市公式で名称は確認済みですが、振り仮名は未確認です。
- 若紫まい、巫薙りんか、乾物ひもの、結稲みなも、烏羽レアは既存登録を使用しています。

追加内容・確認元は [data/additions-fukui.tsv](data/additions-fukui.tsv) を参照してください。原版の方針に合わせ、フルネームだけでなく下の名前・短縮読みからも変換できます（例：てぃな → 歩音ティナ、みゃこ → 越乃みゃこ）。響絵想の「めもりー」は既存登録を使用しています。

## ダウンロード・導入

[dist](dist) から利用するIMEに対応するファイルを1つダウンロードしてください。GitHubのファイル表示画面にある「Download raw file」を利用できます。

| 環境 | ファイル | 文字コード |
| --- | --- | --- |
| Microsoft IME | [MicrosoftIME.tsv](dist/VTuber変換辞書_MicrosoftIME.tsv) | UTF-16LE（BOM付き） |
| Google 日本語入力 | [Google日本語入力.tsv](dist/VTuber変換辞書_Google日本語入力.tsv) | UTF-16LE（BOM付き） |
| ATOK | [ATOK.tsv](dist/VTuber変換辞書_ATOK.tsv) | UTF-16LE（BOM付き） |
| macOS | [macOS.plist](dist/VTuber変換辞書_macOS.plist) | UTF-8 |

各IMEのユーザー辞書のインポート機能で読み込んでください。複数形式を同じ辞書へ登録すると重複する場合があります。原版ver1.0／ver1.1由来の誤登録の削除については、原配布物の更新案内を参照してください。本版には原版の削除専用ファイルを同梱していません。

## 編集と再生成

編集元はUTF-8の [data/master.tsv](data/master.tsv) です。1行が1つの「読み→名前」を表します。名前の表記とIME別品詞は原版を保持しています。`origin` は原版由来が `upstream`、今回の追加が `added` です。追加行の `source_url` と `note` に確認元・留意点を記録しています。

Python 3で、リポジトリ直下から実行します。外部ライブラリは不要です。

```sh
python scripts/build.py
```

必須欄・重複を検査して4形式を生成し、再読込して内容を照合します。`dist` を直接編集せず、`master.tsv` を変更して再生成してください。`additions-fukui.tsv` は初回追加の変更記録です。Excel版は生成していません。

検証済み：原版4形式の読み・名前の一致、元20,014語の保持、追加36語の重複なし、出力4形式の20,050語の一致。実際の各IMEへのインポート操作は未検証です。
