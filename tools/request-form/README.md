# 収録依頼フォーム

F-VTD への収録依頼を受け付ける Google フォームを、[create_form.gs](create_form.gs) で作成します。フォームの設問を変えるときは、このスクリプトを編集して作り直します。

## 作られるもの

- **Google フォーム**：最初に依頼の種類を選び、種類ごとのページを経て共通ページへ進みます。1回の送信につき1名分です。
  - 新規収録：名前の表記、フルネームの読み（必須）、下の名前・愛称などの読み、所属・活動形態
  - 読みの追加：収録済みの名前、追加したい読み（必須）
  - 誤りの訂正：収録済みの名前、誤っている内容（必須）、正しい表記、正しい読み
  - 共通：確認元のURL（必須）、補足、依頼者の立場（必須）、連絡先（任意）、確認事項への同意（必須）
- **回答スプレッドシート**：回答の右に「辞書照合」「対応状況」「対応メモ」列が付きます。対応状況は「未対応／調査中／収録済み／見送り」から選べます。
- **通知**：回答が届くたびに GitHub 上の `data/master.tsv` と照合し、その結果を「辞書照合」列に書き込み、依頼内容と合わせてメールで送ります。

読みの欄は、ひらがなと長音「ー」だけを受け付けます。複数の読みは「、」で区切ります。Google ログインやメールアドレスの収集は求めません。

## 作成手順

作業時間は5分ほどです。フォームとスプレッドシートは、ログイン中の Google アカウントのマイドライブに作られます。

1. <https://script.google.com> を開き、「新しいプロジェクト」を作成します。
2. 最初からある `コード.gs` の中身をすべて消し、[create_form.gs](create_form.gs) の内容を貼り付けて保存します。プロジェクト名は「F-VTD 収録依頼フォーム」などにしてください。
3. 上部の関数の選択欄で `setup` を選び、「実行」を押します。
4. 承認を求められたら、自分のアカウントを選んで許可します。「Google はこのアプリを確認していません」と表示された場合は、「詳細」→「（プロジェクト名）に移動」で進みます。自分で作ったスクリプトなので問題ありません。
   - 求められる権限：フォームとスプレッドシートの作成・編集、外部URLの取得（辞書の照合用）、メールの送信（通知用）、トリガーの作成
5. 実行ログに次の4行が表示されたら完了です。
   - 回答用URL（`https://forms.gle/...`）：README に載せる公開用のリンク
   - フォームの編集画面
   - 回答スプレッドシート
   - 通知メールの送信先
6. 回答用URLを開き、テストとして1件送信します。スプレッドシートに行が追加され、「辞書照合」に結果が入り、メールが届くことを確認してください。確認後、テストの行はスプレッドシートとフォームの「回答」タブの両方から削除します。

## 運用

- 依頼が届いたら、確認元で名前と読みを調べ、「対応状況」を更新します。
- 収録する場合は `data/master.tsv` に追加し、`data/additions.tsv` に確認元を記録してから `python scripts/build.py` で再生成します。フォームの回答から自動で辞書に登録することはしません。
- 「辞書照合」は送信時点の GitHub 上の `master.tsv` との単純な一致確認です。表記ゆれ（全角・半角など）は吸収しますが、別名や旧名は見つけられません。
- 連絡先は依頼者が返信を望んだ場合の記入欄です。公開しないとフォームに明記しているため、Issue やコミットに書き写さないでください。
- 受付を止めるときは、フォームの編集画面の「回答」タブで「回答を受け付ける」をオフにします。

## 作り直すとき

`setup()` は二重に作成しないよう、同じプロジェクトでの2回目の実行を止めます。作り直す場合は次の順で行います。

1. 古いフォームと回答スプレッドシートをドライブから削除します（残す回答があれば先に保存してください）。
2. Apps Script の「トリガー」画面で `handleSubmit` のトリガーを削除します。
3. 「プロジェクトの設定」→「スクリプト プロパティ」の `formId`・`spreadsheetId`・`notifyEmail` を削除します。
4. 編集した `create_form.gs` を貼り直して `setup` を実行します。回答用URLが変わるため、README のリンクも更新します。

設問の文言の軽い修正だけなら、作り直さずにフォームの編集画面で直しても構いません。ただし見出しを変えると、通知メールと辞書照合がその設問を読み取れなくなります。見出しを変えた場合は `create_form.gs` の `Q` も合わせて直し、Apps Script に貼り直してください。
